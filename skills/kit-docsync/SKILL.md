# kit-docsync: 문서 정합 + 최종 커밋

## 1. 문서 채우기 (templates/ 양식)
- **REPORT.md** 첫 줄: 무엇이 되고 무엇이 안 되는지. 이어서 핵심 숫자, 확정/잠정, 다시 볼 ID, 검증 범위, 다음 검증.
- **DECISIONS.md**: 결정마다 채택/대안 숫자·방향·정책이 틀리면 생기는 파급. 변환표는 **실제 코드 순서대로** 전후 건수.
- **PLAN.md**: 단계별 상태를 실제와 맞춘다. "미실시"로 남은 단계가 없게 한다.
- **HANDOFF.md**: 실행 명령, 현재 상태, 남은 일, 미확정 정책과 영향·승인 대상, 모델 선택 이유.

## 2. 대조 (찾으면 고친다, 근거는 만들지 않는다)
- 중복: 같은 내용이 다르게 적힌 곳
- 불일치: 문서 숫자 ≠ 실행 결과, 문서 순서 ≠ 코드 순서, 담당자 답 ≠ 구현
- 누락: 코드가 거르거나 바꾸는데 변환표에 없는 지점
- 모호: "대부분", "약간" 같은 말 → 숫자로
- 큰 숫자 변화는 원인별 기여의 합으로 정확히 분해돼 있는지

## 3. 마무리
- kit-tools `check_submit.py` 실행 → 실패 0건까지
- 커밋. 이후 기능 변경 없음.
