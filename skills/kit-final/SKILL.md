# kit-final: 최종 점검

새 기능·리팩터링 금지. 실패가 나오면 고치지 말고 먼저 보고하고 멈춘다(내가 고칠지 정한다).

## 실행 (이번 응답에서 새로 실행한 출력만 근거로)
1. 지정 명령으로 본 데이터 처음부터 실행 (`run_e2e.py`)
2. 같은 명령으로 자가 홀드아웃 실행
3. 전체 테스트
4. `check_submit.py --require` 제출물 목록
