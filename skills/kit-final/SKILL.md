# kit-final: 최종 점검

새 기능·리팩터링 금지. 실패가 나와도 고치지 말고 먼저 보고하고 멈춘다(고칠지 내가 정한다).
PLAN의 제출 시작 시각이 이미 지났으면 점검을 1·4번만 하고 "즉시 제출"이라고 보고한다.

## 실행 (이번 응답에서 새로 실행한 출력만 근거로)
1. 지정 명령으로 본 데이터 처음부터 (`run_e2e.py`)
2. 같은 명령으로 `~/kit-out/holdout` 자가 홀드아웃
3. 저장소 루트에서 `python -m pytest` (채점기와 같은 방식)
4. `check_submit.py --pytest --require <제출물>` (REQUESTS 미완료·data 변경·미커밋)
