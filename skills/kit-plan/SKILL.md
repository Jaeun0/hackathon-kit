# kit-plan: PLAN + 뼈대 (체크포인트 1)

## 1. PLAN.md (templates 양식)
- 맨 위: 목표 한 문장, 시작 시각, 그리고 **시간 관문을 실제 시계 시각으로** (전체 시간 대비 비율):
  뼈대 22% · 규칙 끝 64% · 검증 끝 78% · **기능 동결 83%** · **제출 시작 94%**
- 단계마다 숫자 완료 조건과 예산(분). 활동형 목표("진행", "개선") 금지.
- 관문에 늦으면: 남은 함정은 DECISIONS에 기본 해석·"미반영"으로 기록하고 다음 단계로 간다.

## 2. 뼈대
- 규칙은 최소로, README의 지정 명령·인자로 처음부터 끝까지 돈다. 데이터 경로 하드코딩 금지, 웹이면 0.0.0.0.
- kit-tools `run_e2e.py`로 **모든 날짜·입력에서 성공 출력**인지 확인한다. 다른 데이터 폴더로도 한 번.
- 웹이면 서버 실행 명령 한 줄과 확인할 경로 2~3개를 보고에 적는다(내가 다른 터미널에서 띄워 본다).

## 보고 후 멈춤 (10줄)
PLAN 관문 시각, run_e2e 실패 수, 커밋 해시, 서버 실행 명령(웹이면).
