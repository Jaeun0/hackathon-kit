# kit-plan: PLAN + 뼈대 (체크포인트 1)

## 1. PLAN.md (templates/PLAN.md 양식)
- 맨 위: 목표 한 문장, 시작 시각, **기능 동결 시각(83%)과 제출 시작 시각(94%)을 실제 시계 시각으로**.
- 단계: 1) 뼈대 2) 규칙 구현(함정 지도 항목 묶음별) 3) 검증 4) 정리.
- 단계마다 **숫자로 된 완료 조건**("본 데이터 모든 날짜 성공 응답", "규칙 테스트 N개 통과", "독립 재계산 차이 0건")과 시간 예산(분).
- 확인 불가 항목은 "기본 해석을 DECISIONS에 기록" 단계로 넣는다.
- 활동형 목표("진행", "개선")는 쓰지 않는다. 무엇이 참이 되면 끝인지와 증거를 쓴다.

## 2. 뼈대
- 규칙은 최소로 두고, README의 지정 명령·인자(`--data`, `--input`, `--port` 등)로 처음부터 끝까지 돌게 만든다.
- 웹 서비스면 0.0.0.0에 바인딩한다.
- kit-tools `run_e2e.py`로 실행해 **모든 날짜·모든 입력에서 형식에 맞는 성공 출력**인지 확인한다.
- 다른 데이터 폴더를 줘도 실행되는지 한 번 확인한다(데이터 경로 하드코딩 금지).

## 보고 후 멈춤
- PLAN 요약 5줄, run_e2e 결과(실패 수), 커밋 해시
- 나에게 "왜" 질문 1개 (예: "이 뼈대에서 날짜 하나가 실패하면 화면에 무엇이 보여야 하나?")

참고: 완료 조건 쓰는 법은 openai/skills `define-goal`(Apache-2.0)의 Goal Quality Bar를 바탕으로 했다.
