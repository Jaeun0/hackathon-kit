# kit-start: 과제 정리 + 데이터 프로파일

## 할 일
1. README·상세 안내·규정·데이터 설명을 읽는다. 상세 안내의 환경 점검(check_setup 등)이 있으면 먼저 실행하고 결과를 한 줄로 적는다.
2. AGENTS.md 맨 아래에 `## 과제 내용`을 추가한다.
   - 목표 / 지정 실행 명령과 인자 / 출력 형식 / 제출물
   - 규칙 요약표 (조항 · 내용 · 기준값 · 이상/초과)
   - **결과를 쓰는 사람과 그 사람이 내릴 결정, 요구한 결과물 형태**(비교표·목록·화면 등). 문서에 없으면 "담당자 확인 필요"로 적는다.
3. kit-tools의 `profile.py`로 data/를 요약한다. 행은 출력하지 않는다.
4. 과제 유형을 판단한다: 웹 서비스 / 집계 / 규칙 판정 / 코드·파이프라인 수정 / 원인 분석. 섞이면 모두 적는다.

## 보고 (15줄 이내)
- 목표와 지정 실행 명령 한 줄씩
- 범주 컬럼 값 표. "대상 아님"을 뜻할 수 있는 값(테스트·시험·예비·폐기·LAB 등)에 ★
- 시간 컬럼의 범위·시간대 표기
- 결측·완전 중복 행 수
- 과제 유형
- 문서에 없는 것: 결과 사용자·결정·요구 결과물 형태
- 나에게 질문 1개

## 하지 말 것
- 구현, 테스트 작성, 함정 확정. 데이터만 보고 규칙을 단정하지 않는다.
