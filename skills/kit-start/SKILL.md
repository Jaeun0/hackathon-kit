# kit-start: 과제 정리 + 요구 체크리스트 + 프로파일

## 할 일
1. README·상세 안내·규정·데이터 설명을 읽는다. 환경 점검 명령(check_setup 등)이 있으면 실행하고 결과를 한 줄로 적는다.
2. AGENTS.md 맨 아래에 `## 과제 내용`을 추가한다: 목표 / 지정 실행 명령과 인자 / 출력 형식 / 제출물 / 규칙 요약표(조항·기준값·이상/초과).
3. **REQUESTS.md**(templates 양식)에 README의 요구 기능을 한 줄씩 적는다. 화면 요소(표·합계·필터·다운로드·강조), API 경로, 출력 파일마다 수용 기준을 "어디서 · 무엇이 · 어떤 숫자로 보이면 완료"로 쓴다. 상태는 모두 `미착수`.
4. kit-tools의 `profile.py`로 data/를 요약한다. 행은 출력하지 않는다.
5. 과제 유형: 웹 화면 / 웹 API / 집계 / 규칙 판정 / 코드·파이프라인 수정 / 원인 분석 (섞이면 모두).

## 보고 (10줄)
- 목표·실행 명령 한 줄씩, 과제 유형
- REQUESTS 요구 수
- 범주 컬럼 값 중 "대상 아님"일 수 있는 값(테스트·예비·폐기·격리·단종 등)에 ★
- 시간 범위·시간대, 결측·완전 중복 수
- 문서에 없는 것: 결과 사용자·결정·요구 결과물 형태

보고 후 멈춘다.
