# kit-trapmap: 함정 지도 + 2차 질문 초안

## 1. 함정 지도 → TRAPMAP.md (커밋)
관점 7개: 대상 범위(범주 값별 포함/제외) / 기준 시점·시간대·정각 / 경계값(이상·초과) / 중복·병합·재시험 / 결측·판단 불가 / 문서 간 불일치 / 변경·예외 문구.
항목마다 칸: 번호(T1…) · 관점 · 근거 위치 · 영향 건수 · 해석 A·B별 차이 · 근거 수준(문서 확정/담당자 필요) · 기본 해석 · 상태(미반영).
- **영향 0건도 빼지 않는다.** AGENTS.md "담당자 확인 사항"의 [미정]도 넣는다.
- "다만·단·예외·별도·제외·이상·미만·초과·이후·변경·버전" 문장은 요약하지 말고 원문을 인용한다.
- 맨 아래에 **명세가 말하지 않는 입력 5개**와 기대 동작 한 줄씩.

## 2. 2차 질문 초안 (6칸, 칸마다 1개, 최대 6개)
1 대상 범위 · 2 기준 시점 · 3 문서 변경점 · 4 예외 문구 · 5 후속 행동(결과를 받은 사람이 다음에 하는 일과 필요한 목록·형태) · 6 사용 방식(누가 언제 어떻게 보고 공유·다운로드하나)
- 질문마다 근거 위치·영향 건수·사례 ID 1개·내 기본 해석을 붙여 네/아니요로 답할 수 있게.
- 5·6칸은 데이터 건수가 0이어도 만든다. 담당자에게 자료를 찾아 달라고 하지 않는다.

## 보고 (10줄)
TRAPMAP 항목 수, 영향 큰 5개 번호, 질문 초안 6개. 멈춘다. 질문 전송은 내가 한다.
