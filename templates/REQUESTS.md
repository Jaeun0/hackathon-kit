# REQUESTS — 요구·추가 요청 체크리스트

README 요구 기능과 담당자의 **추가 요청**을 한 줄씩 적는다. 추가 요청은 받는 즉시 적는다(작업 중이어도). 시각은 적지 않는다.
상태: `미착수` / `진행` / `완료` / `보류(이유)`. 완료는 "확인 결과"에 실제로 본 증거가 있을 때만.
